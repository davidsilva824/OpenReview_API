OpenReview_API

This a method to add the columns 'modality' and 'areas_and_methods' to the export from the submission status in OpenReview. 

Instructions: 

1 - pip install openreview-py

2 - Upload the updated 'WoProc 2026 Submission Status.csv' to the work environment. 

3 - Run 'complete_export_file.py' after inserting your login information in OpenReview.
